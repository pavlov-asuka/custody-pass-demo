# 小托形象基准与生产规范 v1

## 基准资产

`xiaotuo-character-baseline-v1.png` 是小托身份基准，包含挥手全身、讲解半身和头像三种构图。它用于锁定角色身份、轮廓和比例；生产前端资产必须按本规范重绘，不能直接照搬基准图中的浅色调变化。

## 不可变身份

- 白色蓬松小动物，整体是圆润的陪伴型伙伴，不是猫头鹰。
- 头顶蓝色鹿角状装饰；额前有一簇蓝色毛。
- 大黑眼、白色高光、粉色内耳、笑脸。
- 蓝色上衣，胸前不放 AI 字样、品牌标或等级数字。
- 扁平 2D、粗深蓝轮廓、纯色块、无渐变、无写实毛发。
- 不复制 Duo 的体型、眼圈、喙、翅膀或绿色配色。

## 颜色

| 用途 | 建议色值 |
| --- | --- |
| 主体白 | `#FFFDF8` |
| 轮廓深蓝 | `#17324D` |
| 鹿角与额前毛蓝 | `#2F80ED` |
| 上衣主蓝 | `#3B82F6` |
| 蓝色高光纯色 | `#75B6FF` |
| 内耳粉 | `#F6A8B8` |
| 眼睛 | `#101820` |
| 面颊粉（可选） | `#F7B3C2` |

每个封闭区域只能使用一个纯色；不使用透明渐变、阴影渐变、发光或 3D 高光。需要层次时使用第二个明确纯色色块。

## 轮廓与比例

- 轮廓宽度约为画布短边的 2.5%—3.5%，端点和转角圆润。
- 全身高度按 100 计：头部约 48，身体约 32，腿脚约 20。
- 头宽约为身宽的 1.35 倍；双眼间距约一个眼宽。
- 鹿角总宽不超过头宽的 75%，不能形成鸟耳或猫耳轮廓。
- 手脚短圆，姿态重心稳定；避免拟人长手指和写实关节。
- 头像安全区保留头宽 12% 的外边距，鹿角不得被裁切。

## 首批动作

1. `WELCOME_WAVE`：一手挥手，登录和世界入口欢迎。
2. `GUIDE_POINT`：侧身指向内容卡，路线推荐和下一步引导。
3. `READ_WITH_BOOK`：抱书或翻页，知识卡和正常示范。
4. `THINKING`：手托下巴，异常案例作答陪伴。
5. `SCORING_WAIT`：抱计分夹板，异步评分中；不能暗示已通过。
6. `RESULT_SUPPORT`：双手前伸鼓励；通过可庆祝，未掌握不可使用失败或惩罚表情。

当前生产资产统一交付透明背景 WebP，源文件和处理脚本位于 `design-assets/source/phase3b/`。动画只做轻微眨眼、呼吸、挥手或点头，不加入经验值、等级和连续训练元素。

## 制作验收

- 透明背景和像素边界干净；在浅色与深色背景上都能辨认轮廓。
- 64 px 头像仍能识别鹿角、额前毛、大眼和粉色内耳。
- 不出现渐变、猫头鹰特征、Duo 近似轮廓、品牌标、模型名或内部 ID。
- 评分中动作保持中性；结论和路线状态只读取后端字段。
