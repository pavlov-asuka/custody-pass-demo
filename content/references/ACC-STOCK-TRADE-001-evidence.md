## 2. 连续正常案例与答案链

示范使用案例产品 A / 案例股份 A，综合实务使用另一套资料：案例产品 B / 案例股份 D。两套资料均为正常、充分、无冲突的脱敏合成资料。

### 2.1 正常示范：案例股份 A

1. 7 月 10 日期初：20,000 股，股票成本 180,000 元，估值增值 20,000 元；同期资金台账期初余额为 1,000,000 元。
2. 7 月 11 日买入：+10,000 股，成交金额 100,000 元，交易费用 120 元，席位佣金 80 元，实际清算金额按 `-(100,000 + 120 - 80) = -100,040` 元复算。买入后为 30,000 股、成本 280,000 元。
3. 7 月 12 日卖出：-12,000 股，成交金额 132,000 元，交易费用 100 元，席位佣金 90 元，实际清算金额按 `132,000 - 100 = +131,900` 元复算；估值日收盘价为 11.00 元/股。
4. 卖出前单位成本为 `280,000 ÷ 30,000 = 9.333333...` 元/股；题面建议展示保留 2 位小数、判定允许绝对误差 ±0.01；结转成本必须继续按未舍入比例计算为 `280,000 ÷ 30,000 × 12,000 = 112,000` 元，不能把展示值回乘造成关系断裂；结转估值增值为 `35,000 × 12,000 ÷ 30,000 = 14,000` 元。
5. 卖出后剩余 `30,000 - 12,000 = 18,000` 股、剩余成本 `280,000 - 112,000 = 168,000` 元；期末资金为 `1,000,000 - 100,040 + 131,900 = 1,031,860` 元；收盘市值为 `18,000 × 11.00 = 198,000` 元；剩余估值增值为 `198,000 - 168,000 = 30,000` 元。资金、持仓、成本和估值结果闭合。

### 2.2 综合实务：案例股份 D

本案题面批准参数只对本题有效：买入实际清算关系为 `-(成交金额 + 交易费用 - 席位佣金)`；卖出实际清算关系为 `成交金额 - 卖出交易费用`；佣金在交易日确认并形成应付；卖出成本为卖出前成本余额 ÷ 卖出前持仓数量 × 卖出数量；金额按 0.01 元填写。

| 环节 | 计算 | 答案 |
| --- | --- | ---: |
| 买入股票成本 | 成交金额直接形成成本 | 72,000.00 |
| 买入交易费用 | 日报字段单列 | 90.00 |
| 买入席位佣金 | 日报字段，交易日确认应付 | 60.00 |
| 买入实际清算 | `-(72,000 + 90 - 60)` | -72,030.00 |
| 买入后持仓 | `12,000 + 8,000` | 20,000 股 |
| 买入后成本 | `102,000 + 72,000` | 174,000.00 |
| 卖出前单位成本 | `174,000 ÷ 20,000` | 8.70 元/股 |
| 卖出交易费用 | 日报字段单列 | 70.00 |
| 卖出席位佣金 | 日报字段，交易日确认应付 | 40.00 |
| 卖出实际清算 | `51,000 - 70` | +50,930.00 |
| 卖出结转成本 | `8.70 × 5,000` | 43,500.00 |
| 卖出结转估值增值 | `18,000 ÷ 20,000 × 5,000` | 4,500.00 |
| 卖出差额收益 | `50,930 + 70 - 43,500 - 4,500 - 40` | 2,960.00 |
| 卖出后剩余数量 | `20,000 - 5,000` | 15,000 股 |
| 卖出后剩余成本 | `174,000 - 43,500` | 130,500.00 |
| 期末资金 | `520,000 - 72,030 + 50,930` | 498,900.00 |
| 期末股票市值 | `15,000 × 10.20` | 153,000.00 |
| 期末估值增值 | `153,000 - 130,500` | 22,500.00 |
| 勾稽结论 | 资金、数量、成本和估值均可复算 | BALANCED |

买入凭证的结构化方向为：借记股票成本 72,000 元、借记交易费用 90 元；贷记应付佣金 60 元、贷记证券清算款 72,030 元。卖出凭证以证券清算款 50,930 元和交易费用 70 元为借方，贷方补入股票成本 43,500 元、估值增值 4,500 元、应付佣金 40 元和差额收益 2,960 元。这样 PROCESS 30 由字段读取、计算、复算、凭证/台账和跨来源勾稽共同支撑。

## 3. 四环节与评分约束

- 知识卡：三张卡覆盖对象/字段、成本与费用分离、移动加权和结果勾稽边界。
- 正常示范：五步贯穿案例股份 A 的字段读取、买入凭证、日终台账、卖出结转和结果复核。
- 基础练习：Q1 `FIELD_MAP` 字段/来源/正常状态链，Q2 `CALCULATION` 数值取数与复算，Q3 `LEDGER_ENTRY` 局部买入凭证补全，Q4 `RECONCILIATION` 跨来源复算，Q5 `SHORT_TEXT` 业务结论；五项认知动作不同，不是换皮选择题。
- 综合实务：十份资料组成案例股份 D 的正常包，实际 JSON 为 25 个结构化工作项，Rubric `referenceAnswer.responses` 与之逐项对应，覆盖 FIELD_MAP、CALCULATION、LEDGER_ENTRY、RECONCILIATION 和 SHORT_TEXT。
- Rubric 固定为 CONCEPT 25 / PROCESS 30 / RISK 25 / EXPRESSION 20，通过线 75；设置两项硬性必达：买入成本/费用/佣金分离并完成资金关系，卖出移动加权成本与剩余持仓/估值闭合。
- 补学按认知动作命中真实缺口：`R-STK-FIELDS`/`R-STK-COMMISSION` → Q1 字段映射，`R-STK-BUY` → Q2 数值复算，`R-STK-LEDGER` → Q3 凭证科目补全，`R-STK-COST`/`R-STK-RECON` → Q4 移动加权与勾稽，`R-STK-EXPRESSION` → Q5 结论表达；不引入异常案例、升级写作、独立问答或额外评分维度。

## 4. 范围边界

本路线只制作普通交易性股票买入—卖出连续正常业务。历史材料中的特定公司行为、网上申购、特殊市场/特殊产品和异常处理不进入本路线；历史示例费率、税率和精度配置不被写成永久系统规则。地图只在现有生命周期区域追加一个正式股票模块，前置为现有角色节点；不删除或绕过现役节点，不启动第二条路线。
