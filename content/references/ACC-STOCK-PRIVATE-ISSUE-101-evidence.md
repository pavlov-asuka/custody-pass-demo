## 2. 连续正常案例与答案链

示范使用案例产品 G / 案例股份 L，综合实务使用另一套资料：案例产品 D / 案例股份 K。两套资料均为正常、充分、无冲突的脱敏合成资料，且结构同构、数字不同。两套案例都采用全额中签（申购数量 = 中签数量），与材料第 39—41 页示例中“申购金额 = 中签确认金额”的业务关系一致。

### 2.1 正常示范：案例股份 L

1. 8 月 5 日处理前：持仓 0 股，股票成本 0 元，资金台账期初余额 6,000,000 元。
2. 8 月 5 日：业务类型“非公开发行股票”，申购数量 320,000 股，发行价格 12.50 元/股，申购金额 4,000,000 元，支付日期 8 月 5 日，记录状态正常；付款凭证借证券清算款-新股清算款 4,000,000 元、贷银行存款 4,000,000 元；资金台账减至 `6,000,000 - 4,000,000 = 2,000,000` 元，不确认股票成本与持仓。
3. 8 月 12 日：正式中签确认，中签数量 320,000 股，发行价格 12.50 元/股（反填不可修改）；确认成本 `320,000 × 12.50 = 4,000,000` 元。
4. 8 月 12 日：中签凭证借股票-特定对象发行未流通-成本 4,000,000 元、贷证券清算款-新股清算款 4,000,000 元；新股清算款结清。锁定成本 12.50 元/股，锁定起止日期 2026-08-12 至 2027-08-11。
5. 9 月 20 日：最新上市流通公告，上市流通日期 2026-09-28，与中签公告不同；按批准处理更新锁定止日期为 2026-09-27 并与管理人核对确认。
6. 9 月 28 日流通日：系统自动生成流通凭证，借股票-流通-成本 4,000,000 元、借股票-流通-估值增值 208,000 元，贷股票-特定对象发行未流通-成本 4,000,000 元、贷股票-特定对象发行未流通-估值增值 208,000 元；数量 320,000 股、总成本 4,000,000 元不变；市值 `320,000 × 13.15 = 4,208,000 = 4,000,000 + 208,000` 元，勾稽闭合。

### 2.2 综合实务：案例股份 K

本案题面批准参数只对本题有效：2026-10-09 申购付款；2026-10-21 正式中签确认；2026-11-20 按最新公告上市流通；付款阶段只清算不确认成本与持仓；确认成本 = 正式中签数量 × 发行价格；锁定成本默认为发行价格，锁定起止日期按题面批准资料维护；转流通以最新公告为准并把未流通成本及估值增值完整转入流通科目；金额按 0.01 元、数量按整股填写。

| 环节 | 计算 | 答案 |
| --- | --- | ---: |
| 10 月 9 日业务阶段 | 非公开申购付款，等待正式中签确认 | SUBSCRIPTION_PAYMENT |
| 申购付款处理 | 只完成新股清算款与银行存款清算 | PAYMENT_ONLY |
| 申购付款金额 | 申购记录读取 | 3,360,000.00 |
| 付款凭证借方 | 证券清算款-新股清算款 | 3,360,000.00 |
| 付款凭证贷方 | 银行存款 | 3,360,000.00 |
| 付款后资金余额 | `5,000,000 - 3,360,000` | 1,640,000.00 |
| 付款日新增持仓 | 付款阶段不增加持仓 | 0 股 |
| 正式中签确认日期 | 发行结果确认记录读取 | 2026-10-21 |
| 中签数量 | 确认记录读取 | 800,000 股 |
| 发行价格 | 确认记录读取（反填不可修改） | 4.20 元/股 |
| 确认未流通成本 | `800,000 × 4.20` | 3,360,000.00 |
| 中签凭证借方 | 股票-特定对象发行未流通-成本 | 3,360,000.00 |
| 中签凭证贷方 | 证券清算款-新股清算款 | 3,360,000.00 |
| 成本确认时点 | 正式中签确认日 | CONFIRM_DAY |
| 锁定台账 | 锁定成本 = 发行价格；起止 2026-10-21 至 2027-10-20 | LOCK_BY_ISSUE |
| 最新上市流通日期 | 最新公告确定 | 2026-11-20 |
| 日期差异处理 | 按最新公告更新锁定止日期至 2026-11-19，并与管理人核对确认 | UPDATE_BY_LATEST |
| 付款与确认勾稽 | 3,360,000 = 3,360,000，新股清算款结清 | MATCHED |
| 转流通成本结转 | 未流通 3,360,000 → 流通 3,360,000 | 3,360,000.00 |
| 转流通估值增值结转 | 未流通 240,000 → 流通 240,000 | 240,000.00 |
| 转流通后数量 | 800,000 股不变 | 800,000 股 |
| 转流通后市值 | `800,000 × 4.50` | 3,600,000.00 |
| 勾稽结论 | `3,600,000 = 3,360,000 + 240,000`，数量与总成本连续 | BALANCED |

转流通凭证的结构化方向为：借记股票-流通-成本 3,360,000 元；贷记股票-特定对象发行未流通-成本 3,360,000 元；借记股票-流通-估值增值 240,000 元；贷记股票-特定对象发行未流通-估值增值 240,000 元。这样 PROCESS 30 由字段读取、计算、复算、凭证/台账和跨来源勾稽共同支撑。

## 3. 四环节与评分约束

- 知识卡：三张卡覆盖申购付款/正式确认/最新公告状态、字段含义、成本形成时点与转流通连续性。
- 正常示范：五步贯穿案例股份 L 的申购付款读取、付款清算不确认成本、正式确认成本、锁定台账与最新公告、转流通复核。
- 基础练习：Q1 `FIELD_MAP` 付款/确认/公告依据判断，Q2 `ORDERING` 付款→确认→锁定→转流通顺序，Q3 `CALCULATION` 数量×发行价与清算结清复算，Q4 `LEDGER_ENTRY` 付款与确认凭证四科目补全，Q5 `RECONCILIATION` 未流通→流通数量/成本/估值增值/市值跨来源复算；五项认知动作不同，不是换皮选择题。
- 综合实务：十一份资料组成案例股份 K 的正常包，实际 JSON 为 28 个结构化工作项，Rubric `referenceAnswer.responses` 与之逐项对应，覆盖 FIELD_MAP、CALCULATION、LEDGER_ENTRY、RECONCILIATION 和 SHORT_TEXT。
- Rubric 固定为 CONCEPT 25 / PROCESS 30 / RISK 25 / EXPRESSION 20，通过线 75；设置两项硬性必达：正式中签确认前不得确认最终股票成本与持仓、申购付款只完成资金清算；转流通必须使用题面最新有效上市流通公告，数量、成本、估值增值及相关余额完整结转并闭合。
- 补学按认知动作命中真实缺口：`R-PRIVATE-STATUS` → Q1 字段映射，`R-PRIVATE-LOCK-ANNOUNCEMENT` → Q2 状态顺序，`R-PRIVATE-CONFIRM` → Q3 成本复算，`R-PRIVATE-PAYMENT`/`R-PRIVATE-LEDGER` → Q4 凭证科目补全，`R-PRIVATE-TRANSFER`/`R-PRIVATE-EXPRESSION` → Q5 勾稽与结论；不引入异常案例、升级写作、独立问答或额外评分维度。

## 4. 范围边界

本路线只制作原材料所述的“申购付款 → 正式确认 → 数量×发行价格确认未流通成本 → 锁定台账 → 最新上市流通公告 → 转流通数量/成本/估值增值连续”正常业务链。网下新股申购、配股、债转股、要约收购、吸收合并、公司分立、港股供股及供股权证、港股红利税率均为明确排除范围，不进入本路线；普通交易记录、费用佣金、买入卖出移动加权成本由 `ACC-STOCK-TRADE-001` 覆盖，本路线不重复教学。

题面不展示历史菜单、真实证券代码/产品/组合/账户/人员与系统路径；材料第 40 页原文“锁定天数：1天（系统返显）”与示例截图显示的一年期锁定区间存在表面不一致，本路线不将锁定天数写为永久规则，锁定起止日期一律以题面批准资料为准。材料第 39—41 页历史示例（848,009 股 × 7.70 元/股 = 6,529,669.30 元）仅用于推导“中签数量 × 发行价格 = 确认成本”的业务关系，不进入学员题面；案例时间线、发行价格、锁定区间与流通日期均以题面资料包为准。页 42 的流通日股票估值调整凭证与信息披露注意事项已核对但不属于本路线施工范围。
