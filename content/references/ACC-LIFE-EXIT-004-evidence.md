## 2. 连续正常案例与答案链

示范使用案例基金 明溪（可用现金 7,920,000 元），综合实务使用另一套资料：案例基金 云岫（可用现金 5,940,000 元）。两套资料均为正常、充分、无冲突的脱敏合成资料，数字不同但结构同构。

### 2.1 正常示范：案例基金 明溪

1. 最后运作日 2026-10-14，合同终止日 2026-10-15，采用一次清算；余额表：银行存款 7,920,000 元、冻结结算备付金 60,000 元、应收利息 20,000 元、应付费用 8,000 元、份额 7,992,000 份、单位净值 1.0000。
2. 剩余财产 `8,000,000 - 8,000 = 7,992,000` 元；单位净值 `7,992,000 ÷ 7,992,000 = 1.0000` 元；一次清算款 `1.0000 × 7,992,000 = 7,992,000` 元。
3. 管理人垫款 `7,992,000 - 7,920,000 = 72,000` 元：借银行存款 72,000 / 贷其他应付款-应付管理人垫款 72,000；支付清算款 7,992,000 元：借实收资本 7,972,000、借利润分配 20,000、贷银行存款 7,992,000。
4. 支付后现金 `7,920,000 + 72,000 - 7,992,000 = 0`；保留非现金资产 `60,000 + 20,000 = 80,000` 元；负债 `8,000 + 72,000 = 80,000` 元；净资产 0。
5. 后续回收 80,000 元，支付费用 8,000 元、返还垫款 72,000 元，最终现金 `0 + 80,000 - 8,000 - 72,000 = 0`；余额表、资金调节表、估值表全零并完成销户后停止核算。

### 2.2 综合实务：案例基金 云岫

本案题面批准参数只对本题有效：剩余财产 = 资产合计 - 负债合计；单位净值 = 基金资产净值 ÷ 份额，展示 4 位小数、判定容差 ±0.00005；一次清算款 = 单位净值 × 份额；管理人垫款 = 一次清算款 - 可用现金；垫款到账借银行存款、贷其他应付款-应付管理人垫款；支付清算款借实收资本、借利润分配、贷银行存款；余额表、资金调节表、估值表全零且账户销户后停止核算。

## 3. 四环节与评分约束

- 知识卡：三张卡覆盖生命周期状态、一次清算数量关系和最终退出证据。
- 正常示范：五步贯穿案例基金 明溪的终止状态确认、剩余财产/净值/清算款计算、垫款与支付、后续回收与清偿、三表清零与停止核算。
- 基础练习：Q1 `FIELD_MAP` 清盘事实与核算状态映射，Q2 `ORDERING` 生命周期顺序，Q3 `CALCULATION` 剩余财产/净值/清算款/垫款复算，Q4 `LEDGER_ENTRY` 垫款与支付凭证科目补全，Q5 `RECONCILIATION` 现金链、三表清零与停止核算复核；五种认知动作不同，不是换皮选择题。
- 综合实务：十二份资料组成案例基金 云岫的正常资料包，实际 JSON 为 23 个结构化工作项，Rubric `referenceAnswer.responses` 与之逐项对应，覆盖 FIELD_MAP、CALCULATION、LEDGER_ENTRY、RECONCILIATION 和 SHORT_TEXT。
- Rubric 固定为 CONCEPT 25 / PROCESS 30 / RISK 25 / EXPRESSION 20，通过线 75；设置两项硬性必达：剩余财产、单位净值、一次清算款和垫款正确且清算款与份额关系闭合；只有后续资产和负债全部结清、三表全零后才能确认停止核算。
- 补学按认知动作命中真实缺口：`R-EXIT-STATE` → Q1/Q2，`R-EXIT-CALC` → Q3，`R-EXIT-LEDGER` → Q4，`R-EXIT-RECON`/`R-EXIT-CLOSE`/`R-EXIT-EXPRESSION` → Q5；每个补学目标至少被一个评分项或硬性必达引用，无孤儿目标。

## 4. 范围边界

本路线只制作普通契约型开放式基金一次清算的正常退出业务。历史菜单、历史预提金额、历史时点、历史权限、二次清算中的不可变现资产处置方案和复杂清盘算法不进入本路线；违约债券、特殊估值等事项不重复训练。综合实务不含缺失、冲突、迟到、越权、异常升级或风险话术写作。
