## 本案例批准快照与独立答案链

本案例为正常业务资料包。3,500 张申请记录、500 张撤销、3,000 张最终有效、1,000 张行权、2,000 张未行权，以及行权前账簿、完整凭证方向和未行权价格桥均明确标记为本案例批准快照；不扩展为永久规则、税费口径或其他价格源事实。

### 1. 申请、撤销、最终行权/未行权数量链

- 申请记录合计 `3,500 张`。
- 撤销数量 `500 张`。
- 最终有效回售登记数量 = `3,500 − 500 = 3,000 张`。
- 最终有效数量 = `1,000 张最终行权 + 2,000 张未行权 = 3,000 张`。
- 行权比例 = `1,000 ÷ 3,000 = 1/3`，工作项按 6 位小数录入 `0.333333`，容差 `0.000001`。

### 2. 行权前账簿与行权部分结转

- 行权前最终有效持仓：`3,000 张`；成本 `280,800.00 元`；估值增值 `12,000.00 元`；应计利息 `3,000.00 元`。
- 行权部分成本 = `280,800 × 1/3 = 93,600.00 元`。
- 行权部分估值增值 = `12,000 × 1/3 = 4,000.00 元`。
- 行权部分应计利息 = `3,000 × 1/3 = 1,000.00 元`。

### 3. 行权金额与完整借贷凭证

- 行权票面总额 = `1,000 张 × 100 元/张 = 100,000 元`。
- 回售本金 = `101.20 元/每百元票面 × 100,000 元票面总额 ÷ 100 = 101,200.00 元`。
- 行权清算金额 = `101,200.00 + 1,000.00 = 102,200.00 元`。
- 行权日完整凭证（本案例批准快照；清算款借方对象为证券清算款）：
  - 借：证券清算款 `102,200.00 元`；
  - 借：公允价值变动损益 `4,000.00 元`；
  - 贷：债券投资-成本 `93,600.00 元`；
  - 贷：债券投资-估值增值 `4,000.00 元`；
  - 贷：应计利息 `1,000.00 元`；
  - 贷：投资收益 `7,600.00 元`。
- 借方合计 = `102,200 + 4,000 = 106,200.00 元`；贷方合计 = `93,600 + 4,000 + 1,000 + 7,600 = 106,200.00 元`，差异 `0.00 元`。

### 4. 到账日清算款冲销

- 2026-09-02 实际到账 = `102,200.00 元`。
- 到账日凭证：借银行存款 `102,200.00 元`，贷证券清算款 `102,200.00 元`。
- 到账金额与行权日证券清算款相等，冲销差异 `0.00 元`。

### 5. 未行权剩余账簿与价格桥

- 未行权数量 = `3,000 − 1,000 = 2,000 张`。
- 未行权票面总额 = `2,000 张 × 100 元/张 = 200,000 元`。
- 剩余成本 = `280,800 − 93,600 = 187,200.00 元`。
- 剩余估值增值 = `12,000 − 4,000 = 8,000.00 元`。
- 剩余应计利息 = `3,000 − 1,000 = 2,000.00 元`。
- 本案例批准长待偿期价格 = `98.60 元/每百元票面`；价格来源对象是“本案例批准长待偿期估值快照”，只适用题面快照。
- 未行权估值金额 = `98.60 元/每百元票面 × 200,000 元票面总额 ÷ 100 = 197,200.00 元`。
- 本案例批准勾稽关系：未行权估值金额 = `剩余成本 + 剩余估值增值 + 剩余应计利息 = 187,200 + 8,000 + 2,000 = 197,200.00 元`；估值与账簿差异 `0.00 元`，低于 `0.01` 金额容差。

该价格桥只证明本案例题面快照的结构化结果：来源、对象、单位、票面总额、公式和三项账簿均同时成立；不推导其他日期、产品、价格源或通用估值政策。
