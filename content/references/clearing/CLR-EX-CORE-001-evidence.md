# CLR-EX-CORE-001 证据说明

## 路线范围

本路线依赖 `CLR-BASE-001`，只训练正常场内交易确认、清算资料分层、证券/资金清算对象和交收准备。题面把四层资料分开：

1. 成交数据：已确认的业务键、业务日期、证券代码、买卖方向、数量和金额；
2. 清算结果：由成交结果形成的证券应收/应付和资金应收/应付；
3. 交收指令：承接清算结果并形成待执行的交收准备对象；
4. 准备对账：在同一业务键、业务日期和 `security_code` 下逐项比较清算结果与交收指令，确认四项差额为零。

清算结果、交收指令和准备对账资料都必须显式承接成交数据的 `security_code`；不同证券即使数量和金额相同，也不能作为同一批次通过。

案例采用材料支持的买入/卖出总额链，不推导未由材料给出的正式净额算法。买入证券、买入资金、卖出证券、卖出资金分别保留数量或金额及单位；交收指令状态只表示本案例的准备状态，不表示证券或资金已经完成交收。

## A/B 答案链

### Demo A：`CLR-EX-DEMO-A`

- 业务键/日期：`EX-A-20260818-017` / `2026-08-18`。
- 成交确认：两笔买入 `1200 + 800 = 2000 share`，金额 `37440.00 + 9680.00 = 47120.00 CNY`；一笔卖出 `500 share`、`23500.00 CNY`。
- 清算结果四项对象：`security_code=EXA-SEC-01`；买入证券应收 `2000 share`、买入资金应付 `47120.00 CNY`、卖出证券应付 `500 share`、卖出资金应收 `23500.00 CNY`。
- 交收指令和准备对账资料均承接 `security_code=EXA-SEC-01`；四项差额为 `0`、`0.00`、`0`、`0.00`；状态 `RECONCILED`，准备状态 `READY_FOR_SETTLEMENT`。

### Comprehensive B：`CLR-EX-COMP-B`

- 业务键/日期/证券代码：`EX-B-20260821-284` / `2026-08-21` / `EXB-SEC-01`，与 A 不同。
- 成交确认：两笔买入 `900 + 1100 = 2000 share`，金额 `48600.00 + 5500.00 = 54100.00 CNY`；一笔卖出 `700 share`、`18900.00 CNY`。
- 清算结果四项对象（`security_code=EXB-SEC-01`）：买入证券应收 `2000 share`、买入资金应付 `54100.00 CNY`、卖出证券应付 `700 share`、卖出资金应收 `18900.00 CNY`。
- 交收指令和准备对账资料承接同一 `security_code=EXB-SEC-01`；四项差额：买入证券 `2000 - 2000 = 0 share`；买入资金 `54100.00 - 54100.00 = 0.00 CNY`；卖出证券 `700 - 700 = 0 share`；卖出资金 `18900.00 - 18900.00 = 0.00 CNY`。
- 交收准备状态：`READY_FOR_SETTLEMENT`；对账状态：`RECONCILED`。

## 精度、合成值与排除边界

- 数量使用 `share`，精度 0，容差 0；金额使用 `CNY`，精度 2，容差 0.01。
- A/B 的日期、业务键、证券代码、成交编号、数量、金额、单位和状态均标记为 `SYNTHETIC_EDUCATIONAL` + `ONLY_THIS_CASE`，不构成永久制度、费率或时点。
- 2022 版本的固定时点、批次、最低备付比例、费率、账户代码和接口文件名不进入题面或答案。
- 上海/北京货银对付改革参考版仅证明其“测试参考”边界，不作为现行规则。
- 港股通保持 `BUILDING`；QFII/RQFII、改革测试、失败、缺券、资金不足、部分交收、重付、公司行为和系统故障均 `DEFER`。

## 私有映射

`evidence/clearing/ex-core/CLR-EX-CORE-001-evidence.json` 的 `atomicWorkItems` 对公开综合实务每一个 `workItemId` 各提供一条映射，字段包括 `source`、`reference`、`rule` 和 `remediation`；其中 `clr-ex-b-security-code-match` 是四层身份一致性的结构化勾稽项：

- `source`：综合 B 的资料 ID 与字段；
- `reference`：路线 `references[].referenceId` 与材料锚点；
- `rule`：分层、四项汇总、零差和准备状态规则；
- `remediation`：Rubric criterion/mandatory、知识卡或示范步骤、基础题目和补学目标。

证据资产同时保存 A/B 两条 Decimal 复算链和 `FIELD_MAP`、`CALCULATION`、`LEDGER_ENTRY`、`RECONCILIATION`、`SHORT_TEXT` 覆盖清单。
