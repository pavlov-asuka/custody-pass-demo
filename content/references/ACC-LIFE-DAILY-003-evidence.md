## 2. 连续正常案例与答案链

示范使用案例基金 松风（期初现金 2,000,000 元），综合实务使用另一套资料：案例基金 清和（期初现金 1,500,000 元）。两套资料均为正常、充分、无冲突的脱敏合成资料，数字不同但结构同构。

### 2.1 正常示范：案例基金 松风

1. 期初余额表：银行存款 2,000,000 元、投资资产 18,000,000 元、应付费用 40,000 元、份额 20,000,000 份；期初净资产 19,960,000 元。
2. 当日资料：结息单利息收入 15,000 元；费用计提依据计提 3,000 元；支付指令 10,000 元，资金流水显示利息到账 +15,000 元、费用支付 -10,000 元；日间与晚间数据状态均正常。
3. 期末现金 `2,000,000 + 15,000 - 10,000 = 2,005,000` 元；期末应付费用 `40,000 + 3,000 - 10,000 = 33,000` 元；当日净结果 `15,000 - 3,000 = 12,000` 元。
4. 三张凭证：借银行存款 15,000 / 贷利息收入 15,000；借费用 3,000 / 贷应付费用 3,000；借应付费用 10,000 / 贷银行存款 10,000。
5. 期末净资产 `2,005,000 + 18,000,000 - 33,000 = 19,972,000` 元；单位净值 `19,972,000 ÷ 20,000,000 = 0.9986` 元（4 位小数）；资金调节表、电子对账关键项与封账检查表一致后正常封账。

### 2.2 综合实务：案例基金 清和

本案题面批准参数只对本题有效：利息收入按结息单入账（借银行存款、贷利息收入）；费用计提按计提依据入账（借费用、贷应付费用）；费用支付按资金流水实际支付入账（借应付费用、贷银行存款）；单位净值展示 4 位小数、判定容差 ±0.00005；电子对账关键项为银行存款、应付费用；资金调节结平、账簿与估值一致、电子对账一致后正常封账。

| 环节 | 计算/取数 | 答案 |
| --- | --- | ---: |
| 当日利息收入 | 结息单 | 12,000.00 |
| 当日费用计提 | 费用计提依据 | 2,000.00 |
| 当日实际支付费用 | 资金流水 | 8,000.00 |
| 期末现金 | `1,500,000 + 12,000 - 8,000` | 1,504,000.00 |
| 期末应付费用 | `30,000 + 2,000 - 8,000` | 24,000.00 |
| 当日净结果 | `12,000 - 2,000` | 10,000.00 |

凭证方向：利息收入借银行存款、贷利息收入；费用计提借费用、贷应付费用；费用支付借应付费用、贷银行存款。现金账簿期末 1,504,000 元、费用台账期末 24,000 元。

## 3. 四环节与评分约束

- 知识卡：三张卡覆盖日间输入与实际发生、凭证/账簿/估值因果链、第二来源与正常封账。
- 正常示范：五步贯穿案例基金 松风的资料读取、现金/应付/结果计算、三张凭证与台账、估值与单位净值、资金调节/电子对账/正常封账。
- 基础练习：Q1 `FIELD_MAP` 资料与业务含义映射，Q3 `CALCULATION` 取数与现金/应付/结果复算，Q4 `LEDGER_ENTRY` 三张凭证科目补全，Q5 `RECONCILIATION` 净资产/单位净值/对账/封账复核，Q6 `SHORT_TEXT` 业务结论；五种认知动作不同，不是换皮选择题；日链顺序由正常示范与综合实务贯穿验证。
- 综合实务：十三份资料组成案例基金 清和的正常资料包，实际 JSON 为 20 个结构化工作项，Rubric `referenceAnswer.responses` 与之逐项对应，覆盖 FIELD_MAP、CALCULATION、LEDGER_ENTRY、RECONCILIATION 和 SHORT_TEXT。
- Rubric 固定为 CONCEPT 25 / PROCESS 30 / RISK 25 / EXPRESSION 20，通过线 75；设置两项硬性必达：现金、应付费用与当日损益按来源完成计算和账务闭合；账簿、估值表、银行/资金调节和电子对账全部一致后才正常封账。
- 补学按认知动作命中真实缺口：`R-DAILY-SOURCE` → Q1，`R-DAILY-FIELDS` → Q3，`R-DAILY-LEDGER` → Q4，`R-DAILY-RECON` → Q5，`R-DAILY-EXPRESSION` → Q6；每个补学目标至少被一个评分项或硬性必达引用，无孤儿目标。

## 4. 范围边界

本路线只制作普通契约型开放式基金的一条完整正常日链。具体菜单、数据文件名、历史时点、历史费率、异常处理、强制封账和风险话术不进入本路线；股票、债券、期货、货币基金、券结、FOF、ETF 的产品专属核算不重复训练；存款与回购完整核算仍属于资料缺口，不以本路线补造。综合实务不含缺失、冲突、迟到、越权或升级写作。
