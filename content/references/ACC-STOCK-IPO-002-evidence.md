## 2. 连续正常案例与答案链

示范使用案例产品 H / 案例股份 C，综合实务使用另一套资料：案例产品 B / 案例股份 E。两套资料均为正常、充分、无冲突的脱敏合成资料，且结构同构、数字不同。

### 2.1 正常示范：案例股份 C

1. 7 月 15 日处理前：持仓 0 股，股票成本 0 元，资金台账期初余额 500,000 元。
2. 7 月 15 日（T 日）：业务类型“新股申购申请”，申购数量 1,000 股，发行价格 9.32 元/股，预中签信息已取得但未最终交收；不确认股票成本、不确认实际资金变动，持仓保持 0 股、资金保持 500,000 元。
3. 7 月 17 日（T+2 日）：业务类型“新股申购确认”，确认数量 1,000 股、发行价格 9.32 元/股；确认成本 `1,000 × 9.32 = 9,320` 元。
4. 7 月 17 日确认凭证：借股票成本 9,320 元，贷证券清算款-新股清算款 9,320 元；再借证券清算款-其他清算款 9,320 元，贷银行存款 9,320 元；资金台账减至 `500,000 - 9,320 = 490,680` 元。
5. 7 月 17 日收盘价 9.80 元/股：期末市值 `1,000 × 9.80 = 9,800` 元；期末估值增值 `9,800 - 9,320 = 480` 元。资金、持仓、成本和估值结果闭合。

### 2.2 综合实务：案例股份 E

本案题面批准参数只对本题有效：T 日取得申请信息；T+2 日取得最终确认并完成资金清算；申请阶段不确认成本、资金和持仓；确认成本 = 确认数量 × 发行价格；资金清算按确认成本完成且金额一致；金额按 0.01 元填写。

| 环节 | 计算 | 答案 |
| --- | --- | ---: |
| 8 月 5 日资金变动 | 申请阶段不确认实际资金变动 | 0.00 |
| 8 月 5 日新增持仓 | 申请阶段不增加持仓 | 0 股 |
| 最终确认数量 | 8 月 7 日确认记录读取 | 2,500 股 |
| 发行价格 | 8 月 7 日确认记录读取 | 7.60 元/股 |
| 确认股票成本 | `2,500 × 7.60` | 19,000.00 |
| 确认日资金清算 | 确认记录资金清算金额 | -19,000.00 |
| 期末资金 | `860,000 - 19,000` | 841,000.00 |
| 确认后持仓 | 2,500 股（申请阶段不增加，确认后一次形成） | 2,500 股 |
| 确认后股票成本 | 与确认成本一致 | 19,000.00 |
| 单位持仓成本 | `19,000 ÷ 2,500` | 7.60 元/股 |
| 期末股票市值 | `2,500 × 8.40` | 21,000.00 |
| 期末估值增值 | `21,000 - 19,000` | 2,000.00 |
| 勾稽结论 | 资金、数量、成本和估值均可复算 | BALANCED |

确认凭证的结构化方向为：借记股票成本 19,000 元；贷记证券清算款-新股清算款 19,000 元；再借记证券清算款-其他清算款 19,000 元；贷记银行存款 19,000 元。这样 PROCESS 30 由字段读取、计算、复算、凭证/台账和跨来源勾稽共同支撑。

## 3. 四环节与评分约束

- 知识卡：三张卡覆盖申请/确认状态、数量/价格/资金字段、成本与持仓形成时点。
- 正常示范：五步贯穿案例股份 C 的申请读取、不提前确认、最终确认、确认凭证与资金清算、结果复核。
- 基础练习：Q1 `FIELD_MAP` 业务类型/资金变动/成本基础判断，Q2 `ORDERING` 申请→确认状态顺序，Q3 `CALCULATION` 数量×发行价与资金清算复算，Q4 `LEDGER_ENTRY` 确认凭证四科目补全，Q5 `RECONCILIATION` 资金/持仓/成本/估值跨来源复算；五项认知动作不同，不是换皮选择题。
- 综合实务：十份资料组成案例股份 E 的正常包，实际 JSON 为 22 个结构化工作项，Rubric `referenceAnswer.responses` 与之逐项对应，覆盖 FIELD_MAP、CALCULATION、LEDGER_ENTRY、RECONCILIATION 和 SHORT_TEXT。
- Rubric 固定为 CONCEPT 25 / PROCESS 30 / RISK 25 / EXPRESSION 20，通过线 75；设置两项硬性必达：申请阶段不得提前确认股票成本、实际资金变动或新增持仓；最终确认数量、成本、资金、持仓和估值结果必须闭合。
- 补学按认知动作命中真实缺口：`R-IPO-STATUS` → Q1 字段映射，`R-IPO-PREMATURE`/`R-IPO-TIMING` → Q2 状态顺序，`R-IPO-FIELDS` → Q3 成本复算，`R-IPO-LEDGER` → Q4 凭证科目补全，`R-IPO-RECON`/`R-IPO-EXPRESSION` → Q5 勾稽与结论；不引入异常案例、升级写作、独立问答或额外评分维度。

## 4. 范围边界

本路线只制作原材料所述的网上新股信用申购“申请 → 等待最终确认 → 数量×发行价确认成本 → 资金清算 → 持仓/资金/估值勾稽”正常业务。网下新股申购为明确排除范围，不进入本路线；申请阶段不确认成本或实际资金；最终确认后数量、成本、资金、凭证和持仓闭合，确认记录同时提供成本与资金清算字段。历史示例中的真实证券代码、产品、账户、菜单、时点、费率与精度不写成跨产品、跨系统的永久规则；案例时间线与参数均以题面资料包为准。
