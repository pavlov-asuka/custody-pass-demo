# ACC-MF-CARRY-004 证据与闭合说明

## 1. 路线边界与参数结构

本路线只训练普通货币基金运营层的费用计提、损益结转、应付收益和正常收益分配。资产交易费继续归属于 `ACC-MF-EIR-002` 的工具资产层；本路线不重复计算实际利率、溢折价或债券资产成本。所有费用金额、收入、日/月结方式、分配拆分、单位结果、精度和容差都进入题面批准的 `PARAMETER` 快照。

现役路线 Schema 没有独立共享资料包对象。本路线按既有自包含拓扑落地：`PARAMETER → INCOME/FEE LEDGER → 4103 → 4104 → 2232 → DISTRIBUTION/BALANCE WORKPAPER`。演示使用不同于综合的数字和 T+1 日结红利再投；综合使用三日月结资料，在月末同时闭合份额再投资和现金支付。综合案例是本路线独立脱敏批次，不承接其他路线的金额、份额或余额；只复用 EIR 已完成的资产交易费层次定义。

## 3. 正常示范答案链（案例产品甲，T+1日结）

参数：投资收益 7,800.00 元、现金类收入 600.00 元；管理费 1,000.00 元、托管费 240.00 元、销售服务费 180.00 元、银行费用 60.00 元、账户维护费 20.00 元；资产交易费 95.00 元仅作 EIR 边界；期初2232为1,200.00元，期初份额5,000,000份。

1. 收入合计 `7,800 + 600 = 8,400.00` 元；运营费用合计 `1,000+240+180+60+20 = 1,500.00` 元；当日净结果 `6,900.00` 元。
2. 6,900.00 元依次结转至4103、4104和2232；2232分配前余额 `1,200 + 6,900 = 8,100.00` 元。
3. T+1日结只将上一日1,200.00元从2232转入4001实收基金，按1.000000形成1,200份红利再投；当日新收益6,900.00元继续留在2232。
4. 期末份额 `5,000,000 + 1,200 = 5,001,200` 份；期末2232为6,900.00元；资产交易费未进入运营费用。

费用计提凭证为借“运营费用”、贷“应付费用”；T+1红利再投凭证为借“应付收益（2232）”、贷“实收基金（4001）”。

## 4. 综合实务答案链（案例产品乙，月结）

综合资料使用三日独立数字：

| 日期 | 收入 | 运营费用 | 当日净结果 |
|---|---:|---:|---:|
| 9月28日 | 5,200.00 | 1,100.00 | 4,100.00 |
| 9月29日 | 4,900.00 | 1,000.00 | 3,900.00 |
| 9月30日 | 5,100.00 | 1,100.00 | 4,000.00 |
| 合计 | 15,200.00 | 3,200.00 | 12,000.00 |

1. 月末净结果12,000.00元经4103、4104结转至2232，分配前2232为12,000.00元。
2. 本题批准月末分配指令为7,000.00元红利再投、5,000.00元现金支付；两者合计12,000.00元。
3. 期初份额6,800,000份，红利再投按1.000000增加7,000份，期末份额6,807,000份。
4. 期初银行现金3,750,000.00元，现金支付5,000.00元后期末现金3,745,000.00元。
5. 分配后2232为0.00元；分配合计差额、再投资份额差额和现金支付差额均为0，结果 `BALANCED`。

月末凭证层次为：运营费用计提借“运营费用”、贷“应付费用”；红利再投借“应付收益（2232）”、贷“实收基金（4001）”；现金支付借“应付收益（2232）”、贷“银行存款”。现金支付与红利再投均只按本题批准分配指令处理。

## 5. Rubric、补学与排除

- Rubric 固定为 `CONCEPT 25 / PROCESS 30 / RISK 25 / EXPRESSION 20`，通过线75；两项硬性必达分别锁定费用层/4103-4104-2232结转和月末再投资/现金支付闭合。
- 综合 workItem 共28个，覆盖 `FIELD_MAP`、`CALCULATION`、`LEDGER_ENTRY`、`RECONCILIATION`、`SHORT_TEXT`；每个 workItem 均进入 referenceAnswer.responses，并至少被一条 evidenceRules 覆盖。
- 补学目标分别命中费用分层、净结果/结转、凭证、分配方式、余额勾稽和表达结论；不使用异常处置或升级话术评分。
- 不纳入负收益、巨额赎回、交易型货币、直销申购款利息、重要货币市场基金、七日年化收益率计算、节假日披露或任何 YIELD 内容。
