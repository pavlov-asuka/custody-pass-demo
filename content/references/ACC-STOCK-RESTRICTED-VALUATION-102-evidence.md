## 2. 连续正常案例与答案链

示范使用案例产品 A / 案例股份 B（大宗平台受让，6 个月锁定期），综合实务使用另一套资料：案例产品 B / 案例股份 E（非公开发行确认取得，1 年锁定期）。两套资料均为正常、充分、无冲突的脱敏合成资料，示范与综合实务使用同构但不同的数字和案例名称。

### 2.1 正常示范：案例股份 B

1. 7 月 10 日大宗平台受让取得 100,000 股，明确 6 个月锁定期，初始单位成本 9.00 元，锁定成本 900,000 元；台账锁定起始日 2026-07-10、截止日 2027-01-09；受限类型“特定对象发行未流通”，金融工具分类“交易性金融资产”。
2. 题面批准估值快照：S 取估值日收盘价，LoMD=10%，受限估值价＝ROUND(S×(1-LoMD),2)。
3. 7 月 10 日（锁定首日）：收盘价 10.00 元，受限估值价 9.00 元，市值 900,000 元；锁定首日前一日市值＝锁定成本 900,000 元。
4. 7 月 11 日：收盘价 10.50 元，受限估值价 9.45 元，市值 945,000 元；当日估增＝945,000-900,000=45,000 元；估值增值＝945,000-900,000=45,000 元；勾稽：900,000+45,000=945,000 元。
5. 2027-01-05 最新公告明确 2027-01-10 解除限售并上市流通（正常交易日）；2027-01-09 前一日台账市值 990,000 元、估值增值 90,000 元。
6. 2027-01-10 转流通：100,000 股、900,000 元由“股票成本-特定对象发行未流通”转入“股票成本-流通”；估值增值结转＝990,000-900,000=90,000 元；转流通后数量 100,000 股、总成本 900,000 元、估值增值余额 90,000 元连续。

### 2.2 综合实务：案例股份 E

本案题面批准参数只对本题有效：S 取估值日收盘价；LoMD=5%；受限估值价＝ROUND(S×(1-LoMD),2)；受限市值＝受限估值价×锁定数量；估值增值＝受限市值-锁定成本；当日估增＝当日市值-前一日市值；锁定首日前一日市值＝锁定成本；转流通以题面最新公告为准，成本与数量按台账锁定成本与数量结转，估值增值按转流通前一日市值-锁定成本结转；金额按 0.01 元填写、数量为整数股。

| 环节 | 计算 | 答案 |
| --- | --- | ---: |
| 受限属性 | 非公开发行确认取得，发行时明确 1 年锁定期 | RESTRICTED_YES |
| 锁定基础字段 | 确认资料锁定数量 80,000 股、初始单位成本 8.00 元 | LOCK_CONFIRMATION |
| 台账属性 | 特定对象发行未流通 + 交易性金融资产 | TYPE_ALIGNED |
| S 取值 | 估值日收盘价 10.60 元/股（同一股票公允价值参考） | S_CLOSE_PRICE |
| LoMD 取值 | 题面批准流动性折扣 5% | LOMD_APPROVED |
| 受限估值价 | `ROUND(10.60 × (1 - 5%), 2)` | 10.07 元/股 |
| 受限市值 | `10.07 × 80,000` | 805,600.00 |
| 估值增值 | `805,600 - 640,000` | 165,600.00 |
| 当日估增 | `805,600 - 760,000` | 45,600.00 |
| 前一日勾稽 | `760,000 + 45,600 = 805,600` | RV_BALANCED |
| 估值增值账簿科目 | 本案批准名称 | 估值增值-特定对象发行未流通 |
| 估值增值账簿金额 | 当日估增 | 45,600.00 |
| 转流通日期依据 | 最新公告 2027-05-20 | LATEST_ANNOUNCEMENT |
| 转流通数量 | 台账锁定数量 | 80,000 股 |
| 转流通成本 | 台账锁定成本 | 640,000.00 |
| 估值增值结转 | `805,600 - 640,000` | 165,600.00 |
| 转入科目 | 股票成本-流通 | 股票成本-流通 |
| 转出科目 | 股票成本-特定对象发行未流通 | 股票成本-特定对象发行未流通 |
| 转流通后数量 | `80,000 = 80,000` | 80,000 股 |
| 转流通后总成本 | `640,000 = 640,000` | 640,000.00 |
| 转流通后估值增值余额 | `805,600 - 640,000` | 165,600.00 |
| 连续性结论 | 数量、总成本、估值余额连续 | CONTINUOUS |
| 结论表达 | 估值价、市值、估值增值、勾稽一致、转流通连续 | 一段可追溯结论 |

前一日（2027-05-18）台账：受限估值价 9.50 元/股、市值 760,000 元、估值增值 120,000 元，可由 9.50×80,000=760,000 与 760,000-640,000=120,000 复算。转流通工作底稿的估值增值依据与勾稽关系均来自 PDF 第 57 页“估增——前一日台账计算市值-锁定成本”。

## 3. 四环节与评分约束

- 知识卡：三张卡覆盖受限对象与适用边界、资料字段含义、估值价≠普通收盘价及连续性。
- 正常示范：五步贯穿案例股份 B 的受限识别、批准快照取数、估值价/市值/估增计算、账簿补全与前一日勾稽、最新公告转流通与连续性复核。
- 基础练习：Q1 `FIELD_MAP` 属性与字段来源，Q2 `CALCULATION` 估值价/市值/估增复算，Q3 `LEDGER_ENTRY` 转流通成本科目补全，Q4 `RECONCILIATION` 前一日勾稽与转流通连续性，Q5 `SHORT_TEXT` 业务结论；五种认知动作不同，不是换皮选择题。
- 综合实务：十份资料组成案例股份 E 的正常包，23 个结构化工作项，Rubric `referenceAnswer.responses` 与之逐项对应，覆盖 FIELD_MAP、CALCULATION、LEDGER_ENTRY、RECONCILIATION 和 SHORT_TEXT。
- Rubric 固定为 CONCEPT 25 / PROCESS 30 / RISK 25 / EXPRESSION 20，通过线 75；设置两项硬性必达：题面批准估值快照的受限估值价与市值计算正确；转流通前后数量、总成本与估值余额连续闭合。
- 补学按认知动作命中真实缺口：`R-RV-OBJECT`/`R-RV-SOURCE`/`R-RV-DATE` → Q1 字段映射，`R-RV-FV`/`R-RV-CALC` → Q2 数值复算，`R-RV-LEDGER` → Q3 科目补全，`R-RV-CONTINUITY` → Q4 勾稽与连续性，`R-RV-EXPRESSION` → Q5 结论表达；不引入异常案例、升级写作、独立问答或额外评分维度。

## 4. 范围边界

本路线只制作明确限售期股票的受限估值、估值增值入账、前一日勾稽与转流通连续业务。历史菜单、价格参数设置、折扣文件上传、权限配置和系统操作不进入题面；历史 LoMD 公式、价格来源、参数、日期与系统设置不写成永久规则。排除范围（网下新股申购、配股、债转股、特殊公司行为、港股业务、历史税率费率权限）不进入本路线；普通股票买入卖出、费用佣金与移动加权成本由 `ACC-STOCK-TRADE-001` 覆盖，本路线不重复教学；非公开发行的申购、付款与确认流程由 `ACC-STOCK-PRIVATE-ISSUE-101` 覆盖，本路线以其确认后的受限持有为起点。
