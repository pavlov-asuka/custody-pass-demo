# 托管智训营

面向托管业务新人的桌面端学习产品。用户登录后从清算、核算、监督三个学习世界中进入所属条线；当前核算世界已正式开放跨模块核算基础与产品生命周期，以及股票、固定收益、期货、估值对账与信息披露、普通货币基金、券结基金、FOF 和 ETF 模块。

产品已经走通以下纵向闭环：

`三世界入口 → 核算连续地图 → 知识卡 → 正常示范 → 基础练习 → 结构化综合实务 → 异步四维评分 → 定向补学 → 重新完成综合实务 → 通过并解锁`

当前状态和已知限制见 [docs/current-state.md](docs/current-state.md)，技术结构见 [docs/architecture.md](docs/architecture.md)，前端视觉以 [frontend/DESIGN.md](frontend/DESIGN.md) 为唯一事实源。

学员可见文字直接说明资料、字段、计算、状态和下一动作。内部活动类型、字段 ID 与技术状态只保留在提交和评分机制中，页面统一显示为业务中文；现有视觉、路线结构、数字、公式、答案和评分规则不因文字治理改变。

## 当前正式范围

- `ACCOUNTING`：开放；正式内容包含跨模块基础 4 条必修路线、股票模块 4 条必修路线和 4 条非阻挡进阶路线、固定收益模块 4 条必修路线和 5 条非阻挡进阶路线、期货模块 4 条必修路线、估值对账与信息披露模块 5 条必修路线、普通货币基金模块 5 条必修路线、券结基金模块 4 条必修路线、FOF 模块 5 条必修路线、ETF 模块 4 条必修路线。
- `CLEARING`、`SUPERVISION`：内容建设中，不提供虚假路线或进度。
- 跨模块基础为“站上核算岗 → 接管一只新产品 → 每日核算与结果闭环”；“合同终止、清盘与退出”在每日核算后解锁，但不阻挡进入资产模块。股票首条路线以前置“每日核算与结果闭环”为准。股票必修主链为普通买卖与成本、网上新股、现金分红与送转、股息红利税，进阶支线为非公开发行、受限估值、港股通交易和港股通现金分红。
- 固定收益与股票并行，以“每日核算与结果闭环”为共同前置。必修主链为债券买卖与结算、日常计息、派息与到期兑付、基础估值；进阶支线为分销、申购、部分兑付、回售和非交易状态迁移。固定收益不设阶段闸门，进阶支线不阻挡主链。
- 期货与股票、固定收益并行，以“每日核算与结果闭环”为前置。4 条必修路线依次训练合约与方向、开平仓及持仓连续性、日终估值/无负债结算/保证金、资金与持仓多来源勾稽；不设阶段闸门。
- 估值对账与信息披露以“每日核算与结果闭环”为前置，5 条必修路线依次训练年报/中报底稿、财务主表闭环、投资组合与收益附注、季度报告、更新招募与产品资料概要；不设阶段闸门。
- 普通货币基金以固定收益必修主链为前置，5 条必修路线依次训练摊余成本/影子定价框架、实际利率与溢折价日计提、TA 份额和资金时序、运营费用与日/月收益分配、偏离/期限/收益指标及节假日披露；不设阶段闸门，进阶业务继续暂缓。
- 券结基金以“每日核算与结果闭环”为入口，普通证券交收路线另依赖股票买卖基础；4 条必修路线依次训练对象/账户/责任边界、数据完整性与可启动状态、券商交收/佣金/备付金金额链、日终资金/持仓/估值勾稽与正常封账；不设阶段闸门，复杂解析、权益、多券商、跨市场和异常处置继续暂缓。
- FOF 以“每日核算与结果闭环”为入口，5 条必修路线依次训练母基金/被投基金及证据链、申购确认与资金份额、批准 NAV 与持仓估值、返还现金与红利再投、赎回应收实收与正常归档；不设阶段闸门，互认/跨境、特殊合同、转换/转托管、T+0 特殊处理和受控人工操作继续暂缓。
- ETF 以“每日核算与结果闭环”和股票买卖基础为入口，4 条必修路线依次训练产品/份额与一级二级市场边界、PCF/股票篮/现金替代与创设单位净值、申赎确认及证券/资金交收、补券与替代款结算及多来源正常封账；不设阶段闸门，联接、跨市场、跨境、互认/集中申购、券结 ETF 增量、公司行为和商品类 ETF 继续暂缓。
- 路线固定包含知识卡、正常示范、基础练习、综合实务四个环节。综合实务使用正常业务资料包和结构化工作纸，正式验证来源识读、计算、账务填写与跨来源勾稽。
- 评分维度为概念 25、处理步骤 30、风险意识 25、表达规范 20；总分达到 75 且两项硬性必达均满足才通过。

不采用 XP、等级、连续学习、红心、排行榜、商城、独立知识问答或三条线快速切换。首版只设计和验收桌面端。


## 本地验证

在仓库根目录使用 PowerShell：

```powershell
.\scripts\validate-content.ps1
py -3 .\scripts\verify-text-humanization.py
.\scripts\test-backend.ps1
.\scripts\build-frontend.ps1
.\scripts\build-app.ps1
.\scripts\verify-all.ps1
.\scripts\verify-phase4.ps1
```

- `verify-all.ps1` 验证一次通过的基础闭环。
- `verify-phase4.ps1` 验证综合实务未掌握、定向补学、结构化重做、通过、解锁和两条历史快照的完整纵向闭环。
- 两个脚本都使用隔离端口和 `.local/` 下的随机 H2 数据，不触碰日常运行数据。

启动本地 Mock：

```powershell
.\scripts\run-mock.ps1
```

## 技术基线

- Java 17、Spring Boot 3.5.3、Maven、Flyway。
- React 18、TypeScript、Vite 6。
- 本地 Mock 使用 H2；正式配置支持 MySQL。
- 前端生产构建通过 Maven `web` profile 打入同源可执行 JAR。
- Fin-X-Scope 3.0.4 仅作为内网可选 profile；默认构建不解析私有依赖。
- HTTP 契约以 `contracts/openapi.yaml` 为准，正式内容以 `content/` 为准。
