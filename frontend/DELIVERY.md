# 托管智训营正式前端 · 交付说明（视觉与交互重构版）

> 重构日期：2026-07-26　目录：`Repository/frontend/`
> 本次为完整视觉与交互重构：从「管理后台风」重做「学习训练营体验」，桌面端专用。

## 一、设计思路

**定位**：面向托管业务新人的智能案例训练营，不是后台管理系统。全站围绕「路线 → 关卡 → 作答 → 反馈 → 成长」组织体验。

**视觉语言**：「晴空蓝 × 青 × 白」。
- 基底 `#F2F7FE` 浅蓝白，页面带极淡的蓝青径向光晕（fixed 背景），告别米白/深蓝/金色组合
- 主色蓝 `#2563EB`，科技青 `#06B6D4`，三路线色：清算交收=青、估值核算=蓝、投资监督=紫（辨识度辅助色）
- 白色卡片 + 蓝色调阴影；渐变仅用于主按钮、品牌字和进度条，不堆砌
- 全部使用 Lucide 图标与系统字体，无外部字体/CDN/在线图片，内网可离线构建运行

**小托**：重新绘制的蓝色豆形 AI 伙伴（青色触角 + AI 徽章），五种动效（呼吸眨眼/思考摇摆+气泡/欢呼跳跃/挥手/脉冲），在登录欢迎、地图推荐、作答陪伴、评分等待、结果点评、知识问答中承担不同引导角色，非装饰贴图。

## 二、学习地图（本次重构核心）

不再是卡片列表，而是完整的成长+闯关界面：

1. **学员成长面板**：等级徽章（Lv.N + 称号：托管新手/进阶/熟手/能手/专家）、XP 进度条（经验值=历次训练得分总和）、连续训练天数、累计训练次数、最佳得分率、今日已练次数——**全部由真实训练记录推导**（`domain/growth.ts`），无一条虚假数据
2. **小托下一步推荐**：根据真实进度推荐「未练过的案例」或「得分率最低的案例」，配「继续训练」主按钮直达作答页
3. **三路线选择器**：左侧路线卡（图标/名称/已掌握 x/y），切换右侧关卡路径
4. **S 形关卡路径**（`components/RoutePath.tsx`）：
   - 真实案例节点沿 SVG 曲线排布，已完成段路线色实线、未到达段灰虚线
   - 节点三态：已完成（路线色 ✓ + 最佳成绩）、当前可训练（白底脉冲光环）、未解锁（灰锁 + 「完成前置关卡后解锁」）
   - 解锁规则：路线内首个未完成案例为「当前」，其后案例待解锁（由真实记录判定）
   - 案例不足 4 个锚位时，尾部补「筹备中 · 敬请期待」锁定占位节点，明确演示属性
5. **选中案例条**：点击节点展开难度/时长/演示标识/我的成绩/「开始训练 · 再练一次」CTA
6. 全部通关时头部显示「已掌握 N/N 关」绿色标，路径区提示可冲击更高分

## 三、其余页面重构

- **登录页**：蓝色科技面板（网格纹理 + 漂浮小托 + 三路线预览 + 「把每一个业务案例都练成你的经验值」）+ 白色表单侧，第一屏即真实登录
- **案例作答页**：案例头（路线标/演示标/难度/时长）+ 左材料（背景分段、任务编号卡）+ 右 sticky 作答卡（小托提示、字数统计、提交禁用态）
- **提交等待**：小托思考浮层 + 阶段文案轮播 + 滑动进度条（不伪装流式）
- **四维结果页**：总分环形仪表（按得分率变色）+「本次获得经验值 +N XP」徽章（与地图等级联动）+ 小托点评 + 四维卡（维度色顶条 + 分数条 + 展开逐点明细：命中带作答依据引用条，遗漏标「待补充」）+ 学习建议 + 作答原文折叠；不展示 weight 等评分规则
- **训练记录**：列表行带分数、得分率微条、路线标、分页、空态引导
- **知识问答**：左主题目录（路线分组、占位数据重名去重、演示标识）+ 右侧问答气泡（引用依据蓝色 chips、insufficientKnowledge 提示、演示问答标识），一次性 JSON 不伪装多轮
- **导航/状态**：白色玻璃顶栏 + 蓝色 active pill；加载骨架屏、空态小托插画、错误重试统一组件

## 四、修复的问题

1. 学习地图统计改为 `api.listAllRecords()` 分页全量拉取（防御上限 20 页），次数与最佳成绩准确
2. 幂等判断以 **trim 后文本** 为准：实质修改才生成新 `clientRequestId`，网络重试复用原 ID
3. 登录成功后再调 `GET /api/auth/me` 确认服务端会话，以其返回值作为用户态
4. e2e 脚本任何断言失败均以 **非零退出码** 结束
5. 占位案例文案全部去除「真实案例」，改为「实战案例 / 业务案例」

## 六、已知限制

1. 浏览器控制台会记录未登录时 `/api/auth/me` 探测的 401（预期行为，消除需改后端响应语义，未动）
2. Playwright 记录 logout 请求 `ERR_ABORTED`（204 响应连接关闭的记录方式；已实测退出后服务端会话确已失效）
3. 关卡路径锚位目前固定 4 个：单路线案例超过 4 个时，第 4 个锚位之后的案例会复用末位锚点，需后续扩展锚位布局
4. 筹备中占位节点为演示示意，后端尚无路线课程结构接口；新增案例会自动作为可玩节点接入路径
5. 无 Maven 环境下可用启动参数方式同源运行（见 README）；`mvn -Pweb package` 建议带 `clean`
