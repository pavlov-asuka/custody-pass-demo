## 五、字体实测（DESIGN 4.2）

| 文件 | 字重 | 原始字节 | gzip | brotli |
|---|---:|---:|---:|---:|
| nunito-400.woff2 | 400 | 24,828 | 24,856 | 24,832 |
| nunito-500.woff2 | 500 | 24,840 | 24,868 | 24,844 |
| nunito-700.woff2 | 700 | 24,880 | 24,908 | 24,884 |
| noto-sans-sc-400.woff2 | 400 | 1,028,488 | 1,028,821 | 1,028,493 |
| noto-sans-sc-500.woff2 | 500 | 1,029,112 | 1,029,445 | 1,029,117 |
| noto-sans-sc-700.woff2 | 700 | 1,028,864 | 1,029,191 | 1,028,869 |
| **合计（6 文件，无重复）** | | **3,161,012** | **3,162,089** | **3,161,039** |

- 判定：最保守口径（gzip 合计 3,162,089）**严格小于 10,000,000**，通过。
- 测量口径：`npm run build` 生产构建后枚举 `dist/fonts/` 全部字体文件逐文件测量。
- 字符集：ASCII + GB2312 一级字库（3755 汉字）+ 中文标点 +
  frontend/src、frontend/tests、content/、contracts/、backend Java 实际字符，共 3944 字符。
- 覆盖验证：子集后 Noto Sans SC 三字重对全部 3944 字符零缺字；
  Nunito 承担拉丁与数字，中文与符号按字体栈回退 Noto Sans SC。
- 授权：Nunito（SIL OFL 1.1，Nunito Project Authors）与
  Noto Sans SC（SIL OFL 1.1，Adobe，Reserved Font Name 'Source'），
  name 表保留 copyright/license 字段（nameID 0/13/14）。
- 可复现：`python frontend/scripts/build_fonts.py`（fontTools 4.63 + brotli，
  可变字体 instancer → 子集 → WOFF2；源字体 URL 见脚本头注释，源文件不进 Git）。
- 回退栈：`"Nunito", "Noto Sans SC", "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif`，
  `font-display: swap`，`font-synthesis: none` 防止伪造字重。
